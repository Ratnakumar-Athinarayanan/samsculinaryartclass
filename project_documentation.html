Responsive Framework & Interactions 04

The frontend layout follows a mobile-first philosophy, utilizing responsive CSS grids, flexible flexbox directions, and media queries to adapt to any device width.

Adaptive Breakpoints & Rules

Layout adaptations are controlled via custom breakpoints that handle layout shifts, text sizes, and menu visibility:

Breakpoint Target Device Width Layout Adjustments Component State
Mobile Portrait <= 576px 1-column layout, reduced section padding, smaller headings. Navbar menu collapses to a vertical slider. Hamburger icon visible.
Mobile Landscape & Tablets 577px - 768px 1-column or 2-column cards, maps display full-width. Drawer remains toggled by state. Desktop margins reduced.
Desktop Standard 769px - 1200px Grid layouts (3-column courses, 2-column about & contact). Navbar menu items rendered inline. Hamburger icon hidden.
Desktop Wide >= 1201px Maximum page container width capped at 1200px, centered page. Fixed header with blur backdrop. Full floating background bubbles.

Premium Micro-Animations

The layout incorporates micro-animations to enhance user interaction. All buttons, inputs, links, and cards feature high-performance CSS transition durations:

  • Theme Shift Transition: Smooth 0.4s ease background, border-color, and color change transitions on body, cards, and input fields.
  • Interactive Cards: Grid panels translate vertically by -6px and increase box shadow depth on hover with a 0.3s cubic-bezier curve.
  • Hamburger Menu: Seamless CSS height and opacity transitions for mobile submenu overlays.
  • Floating Culinary Bubbles: Slow-rotating blurred background vector shapes that add dimensional depth without impacting page loads.

Search Engine Optimization (SEO) 05

To maximize visibility, the application implements structured local business metadata alongside dynamic page title and keyword overrides.

1. Dynamic Metadata Management (useSEO React Hook)

A custom hook, useSEO.js, dynamically updates metadata properties in the document head when a route is mounted. It handles common search query misspellings: 

import { useEffect } from 'react';

export default function useSEO({ title, description, keywords }) {
  useEffect(() => {
    if (title) document.title = title;
    
    let metaDesc = document.querySelector('meta[name="description"]');
    if (metaDesc) metaDesc.setAttribute('content', description);

    let metaKeywords = document.querySelector('meta[name="keywords"]');
    if (metaKeywords) metaKeywords.setAttribute('content', keywords);
  }, [title, description, keywords]);
}

2. Structured Data (JSON-LD LocalBusiness Schema)

Embedded directly within the root index.html is a JSON-LD payload. This provides search engine crawlers with direct access to physical location metadata:
